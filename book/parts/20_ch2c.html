相关知识

1. 取值范围与溢出

在同一个编译环境中，每种数据类型占用的字节数是固定的，所以能存放的数值也有范围（见⟦表2-18⟧，不同环境中 int 等类型的大小可能不同）。选择类型时，要先想清楚数据可能的最大值和最小值。

⟦表2-18⟧常用数据类型的取值范围（本书环境）

类型字节数取值范围适合存放
char1−128～127一个字符
unsigned char10～255较小的非负整数
short2−32768～32767较小的整数
int4−2147483648～2147483647（约 ±21 亿）一般的整数
long long8约 ±9.2×1018很大的整数
float4约 ±3.4×1038，6～7 位有效数字精度要求不高的小数
double8约 ±1.8×10308，15～16 位有效数字一般的小数（本书统一使用）

如果把超出范围的数存入变量，变量放不下，就会发生溢出，得到一个完全不同的值。下面的程序把 220、380 存入 char 型变量，把 40000 存入 short 型变量：

char 型只有 8 位，最多表示 256 个不同的数。把超出范围的整数存入 char 型或 short 型变量时，得到什么值由编译器决定，C 语言标准没有统一规定。本书使用的 GCC 编译器规定按“绕回来”的方式处理：220 − 256 = −36，380 − 256 = 124，40000 − 65536 = −25536。这就像只有 3 位数字的计数器，999 再加 1 就变成了 000。换一个编译器，结果可能不同。

注意，在本书环境的默认编译选项下，编译器只对 380 给出了警告，对 220 和 40000 没有提示（加上 -Wconversion 选项后才会提示）。所以，不能完全依靠编译器发现溢出，选类型时要先估计数据的范围。另外，int 型数据在运算中超出范围（如两个很大的整数相乘）属于未定义行为，结果无法预料，更要提前避免。

2. 精度

精度是指数据能精确到什么程度。对于带小数的数据，要注意以下三点：

  1. 整型变量不能保存小数。把 24.5 存入 int 型变量，小数部分会被直接舍去，得到 24。
  2. float 的有效数字较少。float 只有 6～7 位有效数字，double 有 15～16 位（见⟦例2-4⟧），本书中的小数一律使用 double 型。
  3. 显示的位数由格式说明符决定。“温度保留 1 位小数”是对输出的要求，用 %.1f 实现；变量本身仍然用 double 型保存。

3. 类型转换

不同类型的数据在一起赋值或运算时，需要先转换成同一种类型。类型转换有两种方式。

（1）自动类型转换。由系统自动完成，常见的有两种情况：一是赋值时，右边的值自动转换为左边变量的类型，如把 24.9 赋给 int 型变量，得到 24；二是运算时，char 型数据先转换为 int 型，int 型与 double 型数据一起运算时，int 型先转换为 double 型，结果也是 double 型。

（2）强制类型转换。在数据前面加上“(类型名)”，把它强行转换为指定的类型，一般形式为：

(类型名)(表达式)

例如 (double)people 把 people 的值转换为 double 型（people 本身的类型不变），(int)sizeof(char) 把求出的字节数转换为 int 型。要转换的是一个表达式时，表达式要加括号，如 (double)(a + b)。

第 5 行把 24.9 存入 int 型变量，得到 24，不是四舍五入。第 6 行虽然 b 是 double 型，但 7 / 2 是两个整数相除，先得到 3，再转换为 3.0。第 7、8 行参加除法的数中有一个是小数，就按小数除法计算，得到 3.5。

4. 整数除法

第 3 点中的 7 / 2 说明：两个整数相除，结果仍然是整数，小数部分被直接舍去。计算座位使用率时，people / seats 就是 36 / 48，结果是 0，再乘 100 还是 0。下面比较三种写法：

写法 A：从左往右计算，先算整数除法 36 / 48 得 0，再乘 100.0，结果是 0.0。写法 B：括号里的整数除法已经得到 0，再转换为 double 型也只是 0.0。写法 C：先把 people 转换为 36.0，再除以 48 得 0.75，乘 100 得 75.0，结果正确。也可以写成 people * 100.0 / seats，让小数先参加运算。

5. 格式说明符要与类型一致

printf 和 scanf 中的格式说明符必须与数据的类型一致（见⟦表2-19⟧）。用错时，本书环境的编译器一般会给出警告（默认编译选项中的 -Wall 会检查格式）。这样的程序属于未定义行为，运行结果没有意义，要先按警告改正，再运行。

⟦表2-19⟧格式说明符与数据类型

类型printfscanf常见的用错写法本书环境中编译器的提示

double%f%lfprintf("%d", temp);

用一个 scanf 输入多个不同类型的数据时，每个格式说明符都要与对应的变量一致，还要检查是否都读入成功。

⟦例2-7⟧　从键盘输入在室人数、温度和故障编码，检查是否都读入成功，再把它们输出。

第 11 行把 scanf 的返回值存入变量 n。三个数据都读入成功时，n 为 3；把人数写成“三十六”时，第一个数据就读不进去，n 为 0，程序给出提示后结束，返回值为 1。如果一个数据都还没读到，输入就结束了（例如直接按 Ctrl+Z 再按回车），scanf 返回 EOF（本书环境中是 −1），它不是读入的数据个数。所以检查时写 n != 3，凡是没有读全 3 个数据的情况，程序都会给出提示并结束。

第 11 行格式控制字符串中 %c 前面的空格不能省略。%c 会把空格、回车也当作字符读入，前面加一个空格，表示先跳过输入中的空格和回车，再读入字符。如果省略这个空格，code 读到的就是 24.5 后面的空格，而不是 g。

6. 字符与字符串不能混用

任务二中讲过，'g' 是字符，"g" 是字符串。写成 char code = "g"; 时，相当于要把字符串 "g" 在内存中的存放位置（地址）存入 char 型变量，这是类型不匹配的写法，编译器会给出警告（见⟦图2-20⟧ 中第 18 行的提示）。这样的程序要先改正，不要运行。

⟦表2-23⟧项目二知识要点

知识点要点
常量与变量直接常量；符号常量 #define 名字 值（不加分号）；只读变量 const。变量先定义后使用，三要素是变量名、类型、值；= 是赋值
数据类型int 存整数；double 存小数（输入用 %lf）；char 存一个字符；_Bool 存 1 或 0。各类型有固定的字节数和取值范围，可以用 sizeof 查看
标识符由字母、数字、下划线组成，不能以数字开头，区分大小写，不能用关键字；起名要见名知意
字符本书环境中字符以 ASCII 码存放：'0' 是 48，'A' 是 65，'a' 是 97，大小写相差 32；转义字符 \n、\t、\\、\'、\"、\0；char 型变量占 1 个字节，字符串 "g" 由 g 和 '\0' 组成，占 2 个字节
数据的输入getchar 读入一个字符；scanf 按格式读入，变量名前加 &；int 用 %d，double 用 %lf，char 用 %c；scanf 的返回值是成功读入的数据个数，使用输入的数据之前，先检查是否读入成功、是否在范围内
数据异常超出范围会溢出；int 不能保存小数；两个整数相除结果是整数；格式说明符要与类型一致。错误必须改正；类型或格式不匹配的警告要先改正、不运行；没有提示不等于没有问题，要用测试数据核对运行结果

AI升华　借助AI完成程序纠错

任务三中，我们自己完成了 bad_lab.c 的异常诊断。本节换一种方式：请 AI 帮忙纠错，再用运行结果逐条检验它的建议。这样做既能提高效率，又能练习判断 AI 回答的对错。

1. 用四要素提问法描述问题

纠错时，提供的材料越完整，AI 的回答越有针对性。除了程序，还要把编译器提示、运行结果和期望结果一起提供。

AI 对话示意编写组整理的示例，实际回答会有所不同

你的程序主要有 5 处问题：

① 第 18 行："g" 是字符串，应改为 char code = 'g';

② 第 14、15 行：温度和湿度有小数，应定义为 double 型，用 %.1f 输出；如果要从键盘输入温度，可以写 scanf("%f", &temp);
