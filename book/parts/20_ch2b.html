任务二实训室设备告警字符加密传输

任务描述

任务一中 203 实训室的教师计算机会向实训中心后台上报告警信息。告警信息使用小写字母 g～n 中的一个代表不同的故障类型（见⟦表2-10⟧）。为了让告警信息在传输过程中不被无关人员直接看懂，约定加密规则：输入一个告警字母，发送其对应大写字母的相邻下一个字母作为加密报文。例如，告警字母 g 对应的大写字母是 G，加密报文就是 H。请编写 C 语言程序实现告警加密报文的显示。

核对要点：传输出错的常见原因有电磁干扰、线路太长导致信号衰减、接口接触不良、网络拥堵造成数据丢失等。加密的作用是让别人看不懂内容，并不能防止出错；要发现传输中的错误，需要使用“校验”（如奇偶校验、CRC 校验），发现错误后再要求重新发送。这些内容会在网络、通信类课程中继续学习。

相关知识

1. 字符

计算机只能存放二进制数（由 0 和 1 组成），字母、数字、符号等字符要先变成整数才能存放。为此，人们给每个字符规定了一个整数编号，叫作字符的编码。最常用的编码是 ASCII 码（美国信息交换标准代码）。本书使用的编程环境与 ASCII 码兼容，英文字母、数字和常用符号的编码就是它们的 ASCII 码，例如字母 g 的 ASCII 码是 103。把字符 g 存入 char 型变量时，内存中存放的其实是整数 103 的二进制形式（见⟦图2-13⟧）。也就是说，字符是以整数形式存放在内存单元中的。

同一个字符型数据，用 %c 输出得到字符本身，用 %d 输出得到它的 ASCII 码。

⟦例2-5⟧　输出字符和它的 ASCII 码。

第 8 行 'g' - 'G' 的结果是 32，说明字符可以像整数一样参加运算，参加运算的是它们的编码。在 ASCII 码中，同一个字母的小写形式比大写形式大 32，因此：

小写字母 - 32 → 对应的大写字母　　大写字母 + 32 → 对应的小写字母

在 ASCII 码中，字母的编码是按字母表顺序连续排列的，所以“大写字母 + 1”就是它在字母表中的下一个字母，如 'G' + 1 就是 'H'。第 9 行还说明：字符 '3' 的 ASCII 码是 51，它和整数 3 不是一回事。

2. 字符集

计算机能使用的全部字符和它们的编码合在一起，叫作字符集。ASCII 字符集共有 128 个字符，编码为 0～127。按用途可以分为字母、数字、专门符号、空格符和不能显示的字符五类（见⟦图2-15⟧ 和⟦表2-11⟧），完整的 ASCII 码表见附录A（）。

只要记住三个“起点”：'0' 是 48，'A' 是 65，'a' 是 97，其他字符按顺序往后数。例如 '3' 是 48 + 3 = 51，G 是第 7 个字母，'G' 是 65 + 6 = 71，'g' 是 97 + 6 = 103。注意：ASCII 字符集中没有汉字，汉字使用 GBK、UTF-8 等编码，一个汉字要占 2 个或更多字节。

说明：本书的字符运算以 ASCII 兼容环境为前提

C 语言标准并没有规定字符必须采用 ASCII 码，只规定了数字字符 '0'～'9' 的编码必须连续，所以 ch - '0' 这类写法在任何环境中都成立。本书使用的小熊猫C++（GCC 编译器）和常见的 Windows、Linux 环境都与 ASCII 码兼容，书中“小写字母减 32 得到大写字母”“字母加 1 得到下一个字母”等做法都以此为前提。

3. 字符常量与变量

1）字符型常量

（1）普通字符。用单引号括起来的一个字符，如 'C'、'g'、'3'、'+'、' '（空格）。使用时要注意：单引号中只能有一个字符；字母区分大小写，'g' 和 'G' 是两个不同的字符；单引号只是字符常量的标志，并不是字符本身的一部分。

（2）转义字符。以反斜杠 \ 开头、后面跟一个或几个字符的特殊字符常量，用来表示不能显示的控制字符，或者在程序中有特殊用途、不能直接写出的字符。例如 '\n' 虽然写了两个符号，但只表示一个字符（换行符，ASCII 码为 10）。常用的转义字符见⟦表2-12⟧。

字符常量用单引号，只能有一个字符；字符串常量用双引号，末尾还有一个 '\0'。char 型变量只能存放一个字符，所以 char code = 'g'; 是正确的，而 char code = "g"; 是错误的写法。任务三中会看到这样写的后果。

3）字符型变量

用 char 定义的变量叫作字符型变量，用来存放一个字符，占 1 个字节。例如：

char type = 'C'; // 实训室类型 char code = 'g'; // 告警字母 char upper; // 大写字母 upper = code - 32; // 小写转大写：103 - 32 = 71，即 'G'

因为字符以 ASCII 码的形式存放，所以字符型变量也可以看作一个“小整数”，能参加算术运算。在本书环境中，char 型变量能存放的整数范围是 −128～127（unsigned char 为 0～255），ASCII 码 0～127 都在这个范围内。char 型是否带符号，C 语言标准没有统一规定，由编译器决定。

4. 字符的输入与输出

任务一中的数据都是直接写在程序里的。而本任务的告警字母每次可能不同，需要在程序运行时从键盘输入。C 语言常用 getchar 函数和 scanf 函数输入数据，它们都在 stdio.h 中。

1）getchar 函数和 putchar 函数

getchar 函数从键盘读入一个字符，putchar 函数输出一个字符，一般形式为：

字符变量 = getchar();　　　putchar(字符);

⟦例2-6⟧　从键盘输入一个字母，再把它输出。

程序运行到第 7 行时会停下来，等待从键盘输入。输入 g 并按 Enter 键后，getchar 读入字符 g，存入变量 c。第 10 行的 putchar('\n') 输出一个换行符。本书的运行窗口中，带下划线的内容是从键盘输入的，输入后都要按 Enter 键。

getchar 读到的字符其实是以 int 型的值返回的（读不到字符时返回 EOF，它是 stdio.h 中定义的一个负数，本书环境中是 −1）。本书只用它读入一个字母，所以直接存入 char 型变量。为了突出重点，⟦例2-6⟧ 这样的演示程序没有检查输入；完整的程序要先检查输入是否成功、是否在允许的范围内，再使用输入的数据（见本任务的任务实施）。

2）scanf 函数

getchar 只能输入一个字符，而 scanf 函数可以按指定的格式输入各种类型的数据，一般形式为：

scanf("格式控制字符串", &变量1, &变量2, …);

例如 scanf("%c", &code); 表示：从键盘读入一个字符，存入变量 code。变量名前面的 & 叫作取地址运算符，&code 表示变量 code 在内存中的位置（地址），scanf 根据这个地址把读入的数据存进去，就像快递员要按门牌号送货一样。scanf 常用的格式说明符见⟦表2-13⟧。

⟦表2-13⟧scanf 常用的格式说明符

变量的类型scanf 中的写法输入示例printf 中的写法
int%dscanf("%d", &people);%d

使用 scanf 时要注意以下几点：

  1. 格式说明符要与变量的类型一致。特别注意，double 型变量输入时要用 %lf，输出时用 %f 即可。
  2. 变量名前面不要漏写 &，否则编译器会给出警告，程序运行时也可能出错。
  3. 一次输入多个数值时，如 scanf("%d %lf", &people, &temp);，输入的数据之间用空格隔开，最后按 Enter 键。
  4. 输入之前，先用 printf 输出一句提示，告诉使用者应该输入什么。
  5. 使用者可能输错，例如把 36 写成“三十六”。scanf 执行后会得到一个整数，表示成功读入的数据个数，叫作 scanf 的返回值。scanf("%c", &code) 读入成功时得到 1；遇到与格式不符的内容，读入就会停下来，得到的数比要读的个数少。没有读入数据的变量，值是不确定的，不能使用。所以完整的程序要先检查 scanf 的返回值，再使用输入的数据。
