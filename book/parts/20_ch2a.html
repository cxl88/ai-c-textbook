1. 常量与变量

程序中的数据有两种表现形式：常量和变量。在程序运行过程中，值不能改变的量叫作常量，如实训室编号 203、总座位数 48；值可以改变的量叫作变量，如当前在室人数、当前环境温度。

1）常量

常量按写法不同，可以分为直接常量和符号常量；此外，用 const 修饰的变量值也不能改变，可以当作常量使用。

（1）直接常量。直接写在程序中、一看就知道值的数据叫作直接常量（也叫字面常量）。按数据类型不同，常用的直接常量见⟦表2-2⟧。

同一个整数可以用不同的进制来写。下面的程序用十进制、八进制、十六进制三种写法表示同一个整数 203，再统一用 %d（十进制）输出：

以 0 开头的整数会被当作八进制数，所以平时写整数时，不要在前面随意补 0（例如把 203 写成 0203，它的值就变成了 131）。

（2）符号常量。用 #define 给常量起一个名字，这个名字叫作符号常量。一般形式为：

#define 符号常量名 常量值

例如 #define ROOM 203。程序编译之前，预处理器会把程序中所有的 ROOM 替换成 203。使用符号常量有两个好处：一是见名知意，看到 ROOM 就知道是实训室编号；二是一改全改，编号变了只需要修改这一行。习惯上，符号常量名全部用大写字母；#define 是预处理指令，末尾不加分号，名字和值之间也不写等号。

（3）只读变量（常变量）。定义变量时在前面加上关键字 const，变量的值在程序运行过程中就不能再修改，相当于一个常量。例如：

const int seats = 48; // 总座位数，以后不能再修改

用 const 修饰的变量叫作只读变量（也叫常变量），它有类型、有名字。只读变量定义以后不能再赋值，所以本书要求在定义时给出初值。C 语言本身允许定义时不给初值，但这样的只读变量以后也不能赋值，就得不到有用的值了。

#define 与 const 都能让数据“固定不变”，它们的区别见⟦表2-3⟧。

（1）变量的定义。变量必须先定义、后使用。定义变量的一般形式为：

类型名 变量名;　或　类型名 变量名 = 初值;

2. 数据类型

数据类型决定了数据在内存中占多大的空间、能表示什么范围的值、能进行哪些运算。C 语言的数据类型可以分为基本类型、构造类型、指针类型和空类型等（见⟦图2-6⟧）。本项目重点学习基本类型中的整型、浮点型、字符型和布尔型。

1）整型

整型用来存放没有小数部分的整数，如人数、座位数、次数。按占用空间的大小，整型分为 short（短整型）、int（整型）、long（长整型）和 long long（长长整型），最常用的是 int。各种整型的字节数和取值范围见⟦表2-5⟧。

⟦表2-5⟧整型的字节数和取值范围（小熊猫C++，64 位 Windows）

类型字节数取值范围适用场合
short2−32768～32767较小的整数
int4−2147483648～2147483647（约 ±21 亿）一般的整数，如人数、座位数（最常用）
long4与 int 相同较少使用（在 Linux 等系统中占 8 字节）
long long8约 −9.2×1018～9.2×1018很大的整数

在类型名前加上 unsigned，表示无符号类型，只能存放 0 和正整数，如 unsigned int 的取值范围是 0～4294967295。同一种类型在不同的编译器、不同的操作系统中占用的字节数可能不同，可以用 sizeof 运算符查看。

3）字符型

字符型（char）用来存放一个字符，如实训室类型 'C'、告警字母 'g'，占 1 个字节，输出时用 %c。例如：

char type = 'C'; // 实训室类型

字符在内存中是怎样存放的、字符能不能参加运算，将在任务二中详细介绍（见）。

4）布尔型

布尔型（_Bool）用来表示“是”或“否”、“开”或“关”这类只有两种状态的数据，如“教师计算机是否开机”。布尔型变量只有两个值：1（真，表示“是”）和 0（假，表示“否”），在本书环境中占 1 个字节；把其他非 0 的值存入布尔型变量，都会变成 1。输出时一般用 %d。

布尔型在后续学习选择结构（根据条件选择执行不同的语句）时会大量使用，本书这里只介绍它的基本用法。C 语言还提供了头文件 stdbool.h，引入后可以写成 bool、true、false，本书暂不使用。

3. 标识符

程序中用来给变量、符号常量、函数等命名的名字叫作标识符，如 people、seats、ROOM、main、printf。标识符分为系统标识符和用户标识符两类。

1）系统标识符

系统标识符是 C 语言事先规定好的标识符，包括关键字和预定义标识符。

（1）关键字。关键字是 C 语言保留的、有特定含义的单词，如 int、double、return，只能按规定的用途使用，不能另作他用。C 语言的常用关键字见⟦表2-7⟧。

小智提示：怎样记住关键字？
  1. 分批记：先记本项目用到的 int、float、double、char、_Bool、const、void、return、sizeof，其他的随着学习逐步掌握。
  2. 联想英文原词：int 来自 integer（整数），char 来自 character（字符），const 来自 constant（常量），sizeof 就是 size of（……的大小）。
  3. 记住特点：关键字都由小写字母组成（_Bool 等少数几个以下划线开头）。
  4. 借助编辑器：在小熊猫C++ 中，关键字会自动显示成蓝色；如果拼错了，颜色就不会变。

（2）预定义标识符。如 printf、scanf、main、define、include 等，它们不是关键字，但在 C 语言中已经有特定的含义（库函数名、主函数名、预处理指令名）。为了避免混乱，不要用它们给自己的变量命名。

2）用户标识符

用户标识符是编程者自己起的名字，如变量名 people、符号常量名 ROOM。用户标识符必须遵守以下规则：

  1. 只能由字母（A～Z、a～z）、数字（0～9）和下划线（_）组成。
  2. 第一个字符必须是字母或下划线，不能是数字。
  3. 区分大小写，age 和 Age 是两个不同的标识符。
  4. 不能与关键字同名。

此外，起名还要做到见名知意：尽量用简单的英文单词，如 age（年龄）、seats（座位数）、temp（温度）；多个单词之间用下划线连接，如 room_num（房间号）。不要用 a、b、c 这类看不出含义的名字，也尽量不用拼音缩写。⟦表2-8⟧ 给出了一些正误示例。
