## 五、程序验证

- 全部 61 个程序都用小熊猫C++ 3.4 自带的 MinGW-w64 GCC 11.5.0 和默认编译选项重新编译。其中 50 个运行过（20 次用了输入数据），11 个只编译。重新运行得到的编译提示、输出和返回值，与排版时使用的结果逐字节一致（链接器提示里的临时文件名每次都不同，不计入）。
- 编译器默认的 C 标准是 gnu17（`__STDC_VERSION__ = 201710L`，已实测）。
- 验证是在 Linux 上用 Wine 9.0 运行同一套 Windows 版编译器完成的，书中的界面截图也来自这个环境。建议在学校机房的 Windows 计算机上抽查复核，特别是安装、中文显示和键盘输入。
